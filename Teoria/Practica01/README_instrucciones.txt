## Dependencias necesarias
Para poder compilar y ejecutar este proyecto, es necesario tener instalado: OpenGL y FreeGLUT.

## Cómo compilar el proyecto
Abrir una terminal en la carpeta donde se encuentra el código fuente (en este caso estar dentro de Practica01) y ejecutar el siguiente comando:
g++ -o Pong Base_Pong.cpp -lGL -lglut -lGLU

## Cómo ejecutarlo
Una vez compilado correctamente, ejecutar el binario generado con:
./Pong

## Controles
- Jugador Izquierdo :
  - Mover hacia arriba: Tecla W
  - Mover hacia abajo: Tecla S

- Jugador Derecho:
  - Mover hacia arriba: Flecha Hacia Arriba
  - Mover hacia abajo: Flecha Hacia Abajo
