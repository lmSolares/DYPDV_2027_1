## Instrucciones de Ejecución

1. Abrir **Unity Hub**.
2. Seleccionar la opción **Open** y navegar hasta la ruta `/Ayudantia/Practica02/`.
3. Una vez que el editor cargue, dirigirse a la ventana **Project** y abrir la escena principal de la práctica.
4. Presionar el botón **Play** (►) para iniciar la ejecución.

## Funcionamiento

Para demostrar el funcionamiento del proyecto, hacer clic izquierdo dentro de la pestaña **Game** una vez que esté en ejecución y hay realizar las siguientes pruebas:

- **Movimiento Lateral:** Al usar las teclas `A` / `D` o las flechas de dirección, el personaje se desplazará, y ahora este automaticamente desacelera.
- **Salto y Gravedad:** Al presionar la tecla `Space` , el personaje realizará un salto, y ahora su salto está limitado, ademas de que no se puede hacer otro salto en el aire.
- **Detección de Suelo:** Se garantiza que el personaje se detiene al toca la plataforma.
