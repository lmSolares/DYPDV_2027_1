## Diseño y programación de Videojuegos
#### Laboratorio - Semana 3

### Objetivo
Tenemos como objetivo en está práctica crear un proyecto 3D en Unity e implementar un controlador para un personaje con movimientos básicos y un sistema para intercambiar entre camaras (FPS/TPS).

### Desarrollo
Para está práctica se siguio la guía que se nos proporciono, para al final tener un personaje que tiene los movimientos básicos y dos perspectivas básicas para casi todos los videojeugos 2D, la primera persona (FPS) y la tercera persona (TPS). 

### Pruebas 
Para poder corroborar que la práctica si cumple con los requerimientos se debe importar el proyecto en Unity y dar en el botón de play en la parte superior central del programa. Despues, una vez se cargue, se puede mover al personaje con a,w,s,d o bien con las flechas, para cambiar entre perspectivas se tiene que oprimir la tecla Tab.
